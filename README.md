# Gameglory · UX-исследователь / продакт-стажёр · «Итог анализа глазами автора игры»

Тестовое задание на позицию «UX-исследователь / продакт-стажёр» (стажёр / джун) в проекте Gameglory, Bear Head Studio.
Нужно синтезировать шесть интервью с инди-разработчиками, спланировать и провести юзабилити-тест
статического прототипа экрана «Итог анализа» (не меньше двух сессий) и дать команде приоритизированные
находки и рекомендации со скриншотами.

Задание — в документе
[`Тестовое_задание_UX_Researcher.pdf`](Тестовое_задание_UX_Researcher.pdf).

> Данные синтетические: люди в интервью вымышлены, игры и числа в прототипе сгенерированы и не описывают
> реальный рынок. Это не выгрузка Steam, датасет не связан с Valve. Совпадения с реальными названиями случайны.

## Состав пакета

| Путь | Что это |
|---|---|
| `Тестовое_задание_UX_Researcher.pdf` | задание: задача, входные данные, что сделать, как сдать |
| `prototype/analysis_summary.html` | статический прототип экрана «Итог анализа»: один файл без зависимостей |
| `interviews/I1_artem.md` … `I6_timur.md` | шесть транскриптов интервью с разработчиками |
| `session_notes_template.md` | шаблон заметок одной сессии юзабилити-теста |

## Как открыть прототип

Откройте `prototype/analysis_summary.html` двойным щелчком или перетащите в окно браузера. Интернет и сборка
не нужны. Для теста по видеозвонку можно показать экран браузера; для теста на телефоне — переслать файл
и открыть его в мобильном браузере.
